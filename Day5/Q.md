Today’s problem: *Three Divisors* – Given an integer n, return true if n has exactly three positive divisors, otherwise return false. 
Hint: A number has exactly 3 divisors only if it’s the square of a prime number (like 4 = 2²) — then its divisors are {1, p, p²}.
